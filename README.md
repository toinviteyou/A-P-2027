# کارت عروسی تحت وب

یک صفحه‌ی وب ایستا (بدون نیاز به سرور) که روی GitHub Pages بالا می‌آید.
مهمان لینک یا QR را باز می‌کند، پاکت را لمس می‌کند، پاکت باز می‌شود، موسیقی پخش می‌شود و دعوت‌نامه ظاهر می‌شود.

## ساختار پوشه

```
index.html          صفحه
css/style.css       رنگ‌ها، فونت‌ها، چیدمان
js/config.js        ← همه‌ی متن‌ها و تنظیمات (فقط همین را ویرایش کنید)
js/app.js           منطق صفحه (دست نزنید)
assets/fonts/       فونت نستعلیق شما
assets/images/      عکس پس‌زمینه
assets/music/       فایل موسیقی
tools/make_qr.py    ساخت QR کد و لینک مهمان‌ها
```

## ۱. شخصی‌سازی (همه در js/config.js)

| چه چیزی | کجا |
|---|---|
| نام عروس و داماد، شعر، متن دعوت، آدرس | `content.fa / en / fr` |
| تاریخ و ساعت | `date.iso` (مثال: `2027-06-12T16:00:00+02:00`) |
| محل روی نقشه | `venue.lat` و `venue.lng` |
| برنامه‌ی روز | `schedule` |
| واتس‌اپ / ایمیل / فرم پاسخ به دعوت | `rsvp` (خالی بگذارید = دکمه نمایش داده نمی‌شود) |
| حذف یک زبان | آن را از `languages` بردارید |

تاریخ شمسی و میلادی خودکار از `date.iso` محاسبه می‌شود.

## ۲. فونت‌ها

- **نستعلیق (Shekasteh):** فقط برای متن دعوت‌نامه در نسخه‌ی فارسی. فایل‌ها: `assets/fonts/nastaliq.woff2` (اصلی) و `nastaliq.ttf` (جایگزین). اگر فونت دیگری خواستید، همین نام‌ها را عوض کنید.
- **Vazirmatn:** برای بقیه‌ی متن‌های فارسی (نام‌ها، تاریخ، عنوان‌ها، برنامه، دکمه‌ها). از خود سایت بارگذاری می‌شود (`Vazirmatn-Regular.woff2` و `Vazirmatn-Bold.woff2`)، نه از گوگل. لایسنس آن OFL است (`Vazirmatn-OFL.txt`).
- انگلیسی و فرانسوی با Cormorant Garamond و Jost (از گوگل‌فونت) نوشته می‌شوند.

اگر خطوط نستعلیق به هم چسبیده یا زیادی دور بودند، در بالای `css/style.css` مقدار `--nastaliq-lh` (فاصله‌ی خطوط) و `--nastaliq-size` (اندازه) را تغییر دهید.

## ۳. عکس پس‌زمینه

- `assets/images/background.jpg`: نسخه‌ی کامل برای کامپیوتر و تبلت.
- `assets/images/background-mobile.jpg`: نسخه‌ی برش‌خورده برای گوشی، طوری که طاق گل تقریباً دور طاق کارت بنشیند. نام آن در `config.js` بخش `imageMobile` است.
- اگر عکس عوض کردید، هر دو نسخه را بسازید (یا `imageMobile` را خالی بگذارید تا همان عکس اصلی روی گوشی هم استفاده شود) و `position` را بسته به عکس تنظیم کنید (`"center top"` یعنی بالای عکس همیشه دیده شود).
- فایل را حتماً JPG واقعی ذخیره کنید (نه PNG که فقط نامش را به jpg عوض کرده‌اید) و حجم هر کدام را زیر حدود ۵۰۰ کیلوبایت نگه دارید.
- اگر عکس روشن است و می‌خواهید رنگ‌هایش زنده‌تر دیده شود، `overlay` را در `config.js` کمتر کنید.

## ۴. موسیقی

**پیشنهاد من: فایل mp3.** مطمئن‌تر از یوتیوب است، چون یوتیوب بعضی ویدیوها را اجازه‌ی نمایش در سایت دیگر نمی‌دهد و برای آهنگ‌های دارای کپی‌رایت ممکن است مسدود شود.

1. فایل را با نام `song.mp3` در `assets/music/` بگذارید (حجم زیر ۵ مگابایت؛ مثلاً ۲ تا ۳ دقیقه با کیفیت 128kbps).
2. اگر نام دیگری گذاشتید، `music.src` را در `config.js` عوض کنید.

برای یوتیوب: `type: "youtube"` و `youtubeId` را بگذارید.

**مهم:** مرورگرها (به‌ویژه گوشی‌ها) اجازه نمی‌دهند صدا بدون لمس کاربر پخش شود. به همین دلیل موسیقی لحظه‌ی لمس پاکت شروع می‌شود، نه قبل از آن. این محدودیت قابل دور زدن نیست. دکمه‌ی بالای صفحه برای قطع و وصل موسیقی است.

## ۵. بالا آوردن روی GitHub Pages

1. در github.com وارد شوید و یک repository جدید بسازید (مثلاً با نامی که به‌راحتی حدس زده نشود).
2. **Add file ← Upload files** را بزنید و همه‌ی محتوای این پوشه را (نه خود پوشه را) بکشید و رها کنید، سپس Commit.
3. **Settings ← Pages ← Source: Deploy from a branch ← Branch: main, پوشه‌ی / (root) ← Save**.
4. بعد از یک تا دو دقیقه آدرس شما می‌شود: `https://USERNAME.github.io/REPO/`

نکات:
- فایل `.nojekyll` از پردازش اضافی جلوگیری می‌کند و باید همراه بقیه آپلود شود (اگر فایل‌های مخفی در آپلود نیامدند، یک فایل خالی با همین نام در گیت‌هاب بسازید).
- با حساب رایگان، repository باید public باشد. یعنی هر کسی که آدرس repository را پیدا کند می‌تواند فایل‌ها را ببیند (آدرس مراسم، عکس‌ها). صفحه برای موتورهای جست‌وجو `noindex` شده است ولی خصوصی نیست.
- پیش‌نمایش لینک در واتس‌اپ و تلگرام: یک عکس `preview.jpg` در `assets/images/` بگذارید و در `index.html` خط کامنت‌شده‌ی `og:image` را با آدرس کامل خودتان فعال کنید.

## ۶. لینک اختصاصی برای هر مهمان

اگر به آخر آدرس `?guest=نام` اضافه کنید، بالای دعوت‌نامه «نام عزیز» نوشته می‌شود:

`https://USERNAME.github.io/REPO/?guest=مریم`

زبان را هم می‌توان تعیین کرد: `?lang=fr` یا `?lang=en`. می‌شود با هم ترکیب کرد: `?guest=Marie&lang=fr`

## ۷. QR کد

```
pip install qrcode[pil]
python tools/make_qr.py https://USERNAME.github.io/REPO/
```

برای ساخت QR و لینک جدا برای هر مهمان، نام‌ها را در یک فایل متنی (هر نام در یک خط) بنویسید:

```
python tools/make_qr.py https://USERNAME.github.io/REPO/ --guests guests.txt --lang fa
```

خروجی در پوشه‌ی `qr/` ذخیره می‌شود و فهرست لینک‌ها در `qr/links.txt` است.

## ۸. آزمایش روی کامپیوتر خودتان

در این پوشه دستور `python3 -m http.server 8000` را اجرا کنید و `http://localhost:8000` را باز کنید.
برای دیدن مستقیم دعوت‌نامه بدون انیمیشن پاکت: `?intro=0` را به آدرس اضافه کنید.
